Saddle & Spoke Conformance checker

Does that site conform?

Point this at any agentic website. It runs the seven interoperability checks from §6 of MVP Profile 0.2 that can be observed from outside the site, and tells you exactly which files answered and which did not. Nothing is installed, nothing is sent anywhere except the site you name.

The last path component is treated as the network name, and the folder above it as the site base — the convention the specification uses. A bare origin checks the first network the manifest lists.

    What it can and cannot see
    
    
    It can see: whether the manifest and definition are reachable from another origin, whether the
       name matches exactly, whether the document is data-only and structurally valid, and whether a
       peer link map exists.
    
    
    It cannot see: whether the site's runtime runs the network correctly, whether consent is asked,
       or whether private context is filtered. Those need a runtime. The workshop
       demonstrates all seven in its Inspector.
