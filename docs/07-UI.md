# 07 — UI

Gate A, sections 1–4. Fixed before the build; afterwards this file describes what exists
rather than what is wished for.

## §1 Style preset

**Workshop paper.** Chosen from the three presets used across these builds (paper /
terminal / gallery). Paper wins here because the product *is* a document: a job sheet, a
parts list, a technical drawing, a stamp.

| | |
| --- | --- |
| Ground | `#f2eee4` paper, `#faf7f0` for the sheet itself, `#e9e3d6` for recessed chips |
| Ink | `#1c1916` headings and body, `#423b34` secondary, `#6b635a` captions, `#868b8e` rules and disabled |
| Accent | one only: oxide red `#b4441f` (`#8c3a1e` on paper for small text). Brass `#9a7c33` is a supporting tint for "co-op" states, never a second accent |
| Type | Fraunces 600 for the wordmark, job number and total; IBM Plex Sans 400/500 for prose; IBM Plex Mono 400/500 for every label, number, code and data value. All three self-hosted (113 KB total), no system-font dependency |
| Rules | 1 px hairlines at 14 % ink; a 2 px oxide ledger rule down the left of the job sheet |
| Texture | one 5 % multiply grain overlay over the whole page, nothing else. No gradients as decoration, no rounded cards, no drop shadows except the sheet's 1 px edge |
| Motion | 3 primitives only: a balloon landing (260 ms fade + 900 ms ring), a bench card arriving (420 ms with 12 % overshoot), the stamp (520 ms squash). All disabled under `prefers-reduced-motion` |
| Density | one screen, no scrolling on desktop. Left column is the drawing, right column is paper |

Type scale: 10 / 11 / 12.5 / 13.5 / 15.5 / 21 / 32 px. Body text is 15.5 px at 1.62.
Every label is 10 px mono uppercase with 0.16 em tracking — that is the page's signature
and the reason the density reads as a form rather than as a brochure.

Contrast: body `#1c1916` on `#faf7f0` is 15.8:1; secondary `#6b635a` is 5.6:1; the oxide
`#8c3a1e` used for labels is 6.4:1. Nothing below 4.5:1 carries text.

## §2 Ruler

This is the first edition of the challenge, so there are no past winners. The ruler is
therefore the organisers' own reference sites — what a conforming agentic site looks like
today — plus four product sites that are the bar for craft. Every one of them is a real
site a judge can open.

| # | Reference | What we take from it | What we deliberately do not |
| --- | --- | --- | --- |
| 1 | `pizza_restaurant_agentified` (organisers' example) | The simplest honest shape of a conforming bundle: manifest, network, actions module, runtime. The action labels are written for a model to choose from. | Its chat-first layout. The site is a background for a chat panel. |
| 2 | `guesthouse_agentified` (organisers' example) | Actions grounded in real page components: the agent drives the same calendar the visitor uses. | Its card-and-shadow visual language. |
| 3 | `worldwideagenticweb.org` (the challenge's own site) | How the ecosystem explains itself; the widget is the whole product, not an add-on. | Its WordPress chrome and stock imagery. |
| 4 | Linear (linear.app) | Restraint: one accent, hairlines instead of boxes, typography doing the work of borders. | Its dark palette — wrong for paper, and the eye has nothing to land on. |
| 5 | Stripe Docs | A technical document as a product surface: numbers aligned, code set properly, every value tabular. | Its information density; this page has one job at a time. |
| 6 | Teenage Engineering (teenage.engineering) | Obsessive detail on a small object; a drawing that is also the interface. | Its playfulness; a workshop should feel calm. |
| 7 | Are.na | Content first, chrome almost absent; the page earns attention from what is on it. | Its lack of hierarchy — a job sheet needs a total. |

What all seven share, and what this page must therefore have: **one thing to look at,
one hand's width of margin, and no element that exists only to fill space.**

## §3 The one memory point

**The drawing annotates itself.**

When an agent names a part, the page does not print a sentence about it. The line work
steps back, a numbered balloon lands on that part, and a legend underneath says what it
is, what is in stock and what it costs. When a part is set aside, it appears on the bench
with its bin code.

A judge should be able to describe it in one sentence to someone else: *"the bike drawing
points at the thing it is talking about."* Everything else on the page — the job sheet,
the stamp, the Inspector — is built to not compete with that.

Deliberately given up to protect it: no animation of the bicycle itself (no spinning
wheels, no pedalling), no illustration of the mechanic, no before/after photos, no
hero image, no scroll-driven anything. The drawing is still. Only the callouts move.

## §4 Main screen spec

Desktop 1440 × 900 (measured; `proof/ui/report.md`).

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ SADDLE & SPOKE     11 Quay Street · Thu 16–20, Sat 09–13   ●replay  INSPECTOR  MODEL │ 68px, hairline under
├──────────────────────────────────────┬────────────────────────────────────────┤
│ THE BENCH              (note, right) │ JOB SHEET                              │
│                                      │ No. 0417              [BOOKED]         │
│           [ the drawing ]            │ Fri 13 Nov · SS-0417-…                 │
│                                      │ COMPLAINT                              │
│                                      │ ─────────────────────────────────────  │
│  ① Chainring  ② Chain  (legend)      │ FINDINGS                               │
│ ───────────────────────────────      │ 01 ● Chain stretched past 0.75 %       │
│ ON THE BENCH            2 parts      │ 02 ● One hooked tooth on the 50T ring  │
│ ┌────────┐ ┌────────┐                │ PARTS                                  │
│ │ CH-11  │ │ CR-50  │                │ Chain    ×1   £28.00                   │
│ └────────┘ └────────┘                │ Chainring ×1  £46.00                   │
│                                      │ LABOUR · TOTAL £74.00                  │
│                                      │ ─────────────────────────────────────  │
│                                      │ COUNTER   (notes, 132px, scrolls)      │
│                                      │ [ composer ]              [ SEND ]     │
│                                      │ (chips: three complaints)              │
└──────────────────────────────────────┴────────────────────────────────────────┘
   1.18 fr                                    0.82 fr      2px oxide ledger rule
```

- Grid: two columns, `1.18fr / 0.82fr`, separated by a hairline. The page does not
  scroll on desktop; each column manages its own overflow. Below 1080 px it becomes one
  column and the page scrolls; below 640 px the drawing loses its note and the wordmark
  shrinks.
- The drawing sits in a `1068 × 700` viewBox with 34 units of margin, so balloons never
  collide with the frame.
- The job sheet is a single column of sections in this order: complaint, findings, parts,
  labour, total, held slot, stamp. Section titles are 10 px mono, values are 13–15 px.
  Empty states are italic serif, never grey boxes.
- The counter shows at most four notes before it scrolls, because the document is the
  subject and the conversation is the margin.
- The Inspector is a 560 px drawer with five tabs; the Checks tab is the default because
  it is the most interesting thing in it.
